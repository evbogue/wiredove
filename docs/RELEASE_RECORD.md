# Release record

Source synchronization and passing CI do not prove deployment. Production proof
requires the host's running revision and matching public asset SHA-256 hashes.
A consumer pin takes effect only when that consumer is deployed.

Use **Newly verified** for observations made in the named run, **Last recorded**
for earlier evidence, and **Unknown** when no current observation exists. Never
silently re-date an old observation. Keep config/key values and identity backups
out of release records.
